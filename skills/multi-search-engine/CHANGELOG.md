# Changelog

All notable changes to this skill will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-22

### Added
- Initial release of Multi Search Engine skill
- Integration of 17 search engines (8 domestic, 9 international)
- SKILL.md with comprehensive documentation
- References directory with advanced search guides
- Support for advanced search operators
- Time-based filtering options
- Privacy-focused search engines
- DuckDuckGo Bangs shortcuts
- WolframAlpha computational queries
- Examples for common use cases

### Search Engines Included

#### Domestic (China):
1. Baidu (百度)
2. Bing CN (必应中国版)
3. Bing International
4. 360 Search (360搜索)
5. Sogou (搜狗)
6. WeChat Search (微信搜索)
7. Toutiao Search (头条搜索)
8. Jisilu (集思录)

#### International:
1. Google
2. Google Hong Kong
3. DuckDuckGo
4. Yahoo
5. Startpage
6. Brave Search
7. Ecosia
8. Qwant
9. WolframAlpha

### Features
- No API keys required
- Web crawling via `web_fetch` tool
- Support for advanced search operators
- Time-based filtering
- Privacy-focused options
- Computational knowledge queries
- Comprehensive documentation
- Best practices and usage examples
